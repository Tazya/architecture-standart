Задачи для реализации в рамках проекта:

## Инфраструктура
1. Развернуть инфраструктуру для микросервиса ставок, включая базу данных, средства мониторинга и логирования.
2. Настроить систему CI/CD для автоматического развертывания и тестирования микросервиса ставок.
3. Настроить систему обмена файлами для партнёрского кол-центра, включая почтовый сервер и механизм генерации файлов с актуальными ставками.

## Разработка
1. Реализовать микросервис ставок, который будет отвечать за хранение и предоставление актуальных ставок по депозитам.
2. Реализовать логику обновления ставок в микросервисе ставок на основе данных из АБС.
3. Реализовать API для системы кол-центра банка, который будет предоставлять актуальные ставки.
4. Добавить интеграцию системы кол-центра банка с микросервисом ставок для получения актуальных ставок.
5. Реализовать механизм генерации и отправки файлов с актуальными ставками в партнёрский кол-центр.
